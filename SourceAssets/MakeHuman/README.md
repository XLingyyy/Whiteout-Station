# MakeHuman v0.2 character sources

`Characters/EngineerGuHeng/WS_Engineer.fbx` and
`Characters/DoctorYeCheng/WS_Doctor.fbx` are deterministic exports generated by:

```powershell
powershell -ExecutionPolicy Bypass -File Tools/Assets/generate_makehuman_characters.ps1
```

The script downloads the official MakeHuman 1.3.0 Windows community package and
the official `suits03` asset pack, verifies their pinned SHA-256 values, installs
MakeHuman per-user when needed, loads the one-shot plugin in
`Tools/Assets/MakeHumanPlugin/9_ws_autogen`, exports both characters with the
MakeHuman `game_engine` skeleton, and copies the FBX plus referenced textures
into this directory.

Each character directory also contains four 30 fps animation-only FBX files:
`Idle`, `Gesture`, `Guarded`, and `Work`. They are generated from the same rig
and imported as `AN_WS_*` sequences. The Unreal import utility creates the
skeletal meshes, shared per-character skeletons, animation sequences, and
`ABP_WS_Engineer` / `ABP_WS_Doctor` under
`/Game/WindStation/Art/Characters/`.
