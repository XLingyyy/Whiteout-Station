## V7-01 用户内容保护

验收标准：

- [x] 从用户当前地图和人物模型建立可追溯基线；
- [x] 工作在独立分支和独立工作树；
- [x] 不改写用户手动摆放后的地图；
- [x] 不修改顾衡、叶澄现有人物模型资产；
- [x] 保护目录新增内容必须在允许清单中。

结果：用户地图和两个人物资产的 Git 对象均与基线匹配；仅新增 12 个动画
资产。

## V7-02 HUD、准心与交互提示

验收标准：

- [x] 左侧面板长文本不会越过面板边界；
- [x] 默认准心为空心圆；
- [x] 聚焦可交互对象时准心切换为手形；
- [x] 准心以视口中心定位；
- [x] 交互提示文字和墨刷背景保持同一中心与缩放关系；
- [x] 720p、1080p 均通过自动像素审计。

结果：两种分辨率下中心误差均不超过 1.5 px。

## V7-03 交互覆盖

验收标准：

- [x] 每个权威规则行动在场景中存在入口；
- [x] 缺失入口不要求改写用户地图；
- [x] 交互追踪不依赖导入网格体是否具有复杂碰撞；
- [x] 行动预览、资源方案切换和确认链路可由真实输入完成。

结果：运行时只在检测到缺失时补入 `distribute_food` 入口，并为交互对象建立
不可见的 query-only 碰撞盒。

## V7-04 AI 表演契约

验收标准：

- [x] 模型输出精确限制为六字段；
- [x] 移动和反应采用固定枚举；
- [x] 非法 JSON、缺字段、额外字段和非法枚举全部拒绝；
- [x] 模型无法修改 AP、资源、事实、承诺、任务、评分和结局；
- [x] 模型引用事实必须来自本地提供的事实 ID。

结果：Agent 测试 48/48 通过，线上与离线权威结果一致。

## V7-05 NPC 移动安全

验收标准：

- [x] 单步移动距离由本地配置限制；
- [x] 移动经过碰撞和空间余量检查；
- [x] NPC 不得无限远离岗位；
- [x] 移动受速度和冷却控制；
- [x] 无效移动请求安全回退。

结果：单步 85 cm、速度 82 cm/s、岗位半径 185 cm；顾衡和叶澄探针均通过。

## V7-06 动画

验收标准：

- [x] 顾衡、叶澄各有行走动画；

## 最终定义

v0.7 的功能、工程、测试和本机评审交付均完成。公开发布门禁仍包含两项：

1. 解决 Noanoa 发型的嵌入与再分发许可；
2. 如需面向普通 Windows 用户发布，对可执行文件进行代码签名。
