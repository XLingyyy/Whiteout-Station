# v0.2 真人体验反馈（脱敏执行摘要）

来源文件保留在本地并被 Git 忽略；本摘要不包含测试密钥或其他凭据。

## UI

- 统一为低遮挡、模块化局部黑色/蓝黑毛玻璃；适度模糊、细颗粒、冷色调。
- 菜单与状态卡使用紧凑圆角面板；准心提示、交互信息与临时通知使用中央深、边缘不规则且透明渐隐的墨刷底板。
- 白/灰白文字分层；橙色仅用于 AP、警告、当前交互目标。
- 可交互物使用细白描边，禁止整体发光材质。
- 呼出查看信息面板时显示鼠标并分离游戏输入。
- 5 张参考图分别覆盖 ESC、对话轮盘、证据板、HUD、交互信息卡。

## 场景与角色

- 反馈指出悬空、穿模、不符合用途和阻塞动线的陈设较多，需逐屋重审。
- `Scene_01`–`Scene_05` 主要覆盖悬空控制台/椅子/柜体、书架卡门、油罐穿模和室内误用户外锈蚀楼梯。
- `Scene_06`–`Scene_10` 主要覆盖角色白眼/怪异抬手、设备浮空、医疗角色姿势与床头/书架阻塞。
- NPC 应只在玩家靠近时转头注视，身体保持原朝向；离开后回正。

## 体验

- 流程改为先按 F 与 NPC 进入对话，再选择交涉方式，并提供轮盘+自由输入。
- 自由输入固定调用 `deepseek-v4-flash`；模型只做意图与表达，不改状态或规则。
- ESC 增加 FOV 与音量设置。
- AP 消耗映射为具象时钟，AP 耗尽时抵达暴雪结算时刻。
- 增加空格跳跃。

详细的范围、规则护栏和验收标准以 `风雪站_断电前夜_开发实施任务清单_v0.3.md` 为准。
