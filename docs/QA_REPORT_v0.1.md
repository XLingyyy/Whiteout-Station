## 软锁与失败路径

- 无效行动在预览/提交两层拒绝，不扣 AP、不写事件。
- 2 AP 行动跨越 4 AP 阈值时危机仅触发一次。
- 最后一个付费行动把 AP 降为 0 后，仍保留 0 AP 发报窗口。
- 强行自行维修只能使用一次；无合作、无替代件时仍有明确失败结局，不进入无响应状态。
- 模型关闭、超时、非法 JSON、改变决定、提交状态字段、越权事实 ID 或未标注的受保护事实短语时均回退本地台词。
- 每次有效行动自动存档；C 键或 `-WhiteoutContinue` 可恢复；R 键重开。

## v0.1 已知表现边界

- NPC 使用程序化防寒服轮廓，没有面捕、口型或配音。
- 共享模型入口面向本地/受控代理，不在仓库保存任何密钥；无端点时设计为完全离线。
- 本轮为自动化与开发者烟测，尚未收集外部真人盲测的时长与主观问卷；该项不阻塞可玩构建，但应作为 v0.2 平衡输入。
