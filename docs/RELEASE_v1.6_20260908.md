### 尚未关闭的质量问题

1. Editor 批次 5 条在线拒绝：顾衡治疗后配合意愿、多意图中的供电追问、提议链的维修进度／履行追问、临时支持持续时间。包含真实越界候选的拦截，也包含语义误判；具体句子在 QA JSON 中保留。
2. 个别已提交台词仍有执行者／患者代词混乱。例如 Editor 包扎链出现“我在行动面板上对你执行……选择顾衡”；Shipping 私聊转述链出现由顾衡说“我在行动面板上确认”。实际动作对象与提交仍由本地规则决定，但表述会误导玩家。
3. 核查器会把泛指“全站受影响”误读成全站供暖停止；也可能漏掉附带细节。Shipping 新问法把包扎笼统称作“临时支持”，与游戏的独立治疗方法容易混淆。现有核查不能据此宣称硬事实错误为零。
4. 连续追问时部分回答重复完整治疗步骤、反复强调旧情况，角色自然度尚不足。八人盲测表已备好，状态保持未执行：[盲测记录](QA/v1.6_blind_test.md)。
