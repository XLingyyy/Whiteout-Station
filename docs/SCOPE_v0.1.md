# v0.1 范围基线

## 必须完成

- 一张可行走的气象站地图：控制室、维修间、医务室、厨房/宿舍、室外天线区。
- 8 AP 行动流程；跨过 4 AP 时只触发一次备用电池危机；AP 归零前保留 0 成本发信窗口。
- 13 项核心行动、至少 6 项证据、至少 3 条代价不同且不超过 8 AP 的成功路线。
- 食物、燃料、药品、隐藏保温包、替代继电器、区域供暖与每 AP 环境结算。
- 玩家、顾衡、叶澄的健康、体温、饱腹状态和精力；NPC 额外具有压力、信任、知识边界和承诺反应。
- 发电机 2/2、天线 1/1、发送求救信号；统一终局与四类结局。
- 任务质量、人员状态、有效储备、社会稳定、信息责任五维评分与因果时间线。
- 无生成模型时可完整游玩；共享模型只负责受约束表达，超时、坏 JSON 或事实越权时自动降级。
- 每行动快照、事件日志、幂等事务、路线回放、自动测试、重新开始与 Windows 可运行构建。

## 暂不制作

- 战斗、制造树、复杂背包、开放世界、随机地图或多人模式。
- 多日天气、第四名 NPC、随机内鬼或全天候 NPC 自主模拟。
- 完整配音、自由语音输入、复杂面部动画、复杂移动与大量随机事件。
- 自由文本不是通关必需；若时间不足，优先删除自由文本解析和额外表达变体。

## 变更规则

新增内容默认标记为 M2。只有当它能明确说明改变的玩家决策、AP 成本、交互状态和模型调用影响时，才进入候选范围。任何动作成本、前置条件、状态差值或评分权重变更，都必须重新运行三条路线和边界回归。
