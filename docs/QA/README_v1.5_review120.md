## 填写方式

1. 用 Excel 打开文件，在“开始审核”填写审核者和日期。
2. 进入“120条审核”，从第 7 行开始。先阅读 A–D 的场景、上文和玩家输入，再填写黄色 E–H。
3. E 用自然语言写对谁、想问什么或做什么；F 选择是否需要追问；G 选择承诺关系。重述、修改或多种承诺关系可选“其他／多项（见说明）”，在 E 或 H 解释。
4. 需要追问时，在 H 写缺少的信息或应追问的问题；拿不准可选“不确定”。每行独立，不延续上一行的世界状态。
5. 可每次填写 20 条，保存原文件，并告知已完成编号范围。自动统计“已填写”仅表示填写完成，不代表模型验收通过。
