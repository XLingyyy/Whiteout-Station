# GATE G2 v0.4 — 黑色毛玻璃 UI 体系

日期：2026-07-22
结论：**PASS**

## 验收结果

- HUD、暂停、设置、证据板和底部对话条统一使用公共毛玻璃面板与 v0.3 token。
- HUD 改为低遮挡模块化布局，去除叠字和 NPC 肖像；右侧人物信息不再拉伸。
- 暂停与设置页完成视觉迁移，无功能的保存/读取/主菜单入口保持明确禁用。
- 证据板完成五类过滤、计数、卡片和详情区视觉迁移；1280×720 无按钮重叠或文本溢出。
- 全屏面板四边干净，主 HUD、交互提示和准心不会透出。

## 双分辨率与性能

- 70 个最终视角均包含 1280×720 与 1920×1080，共 140 张 PNG。
- UI 类视角 42 个，覆盖 HUD、暂停、设置、证据、预览、对话、结算和开场。
- 1080p Shipping：平均 109.34 FPS，1% Low 98.96 FPS。
- v0.3 对照为 101.40 / 84.42 FPS；平均和 1% Low 分别提升约 7.8% / 17.2%，没有毛玻璃性能回退。

证据：`docs/baseline_v0.4/`、`docs/evidence_v0.4/g5_shipping/performance_1080p.json`。

结论：V4-06 至 V4-09 均通过，G2 关闭。
