# 风雪站 v0.3 UI 视觉规范

更新日期：2026-07-22
适用范围：HUD、ESC 菜单、证据板、对话轮盘、交互信息卡、行动预览、拒绝、toast、开场、危机与结算。

## 1. 视觉方向

界面采用低遮挡、模块化的局部黑色毛玻璃体系。信息背衬只包裹必要内容，不使用整屏不透明矩形。主气质为冷峻、克制、电影化和高可读；结构依靠明度、字号和留白建立，橙色不承担普通装饰。

交互信息、准心提示与短时通知使用墨刷底板：中央深、边缘不规则、向外柔和透明。菜单、人物卡和证据卡使用紧凑毛玻璃面板。可交互物保留原材质，仅使用细白轮廓，不再覆盖整物体的蓝色发光层。

## 2. Design tokens

|---|---:|---|
| `WS.Surface.Deep` | `#05090D` / 88% | ESC、证据板主面板 |
| `WS.Surface.Panel` | `#09121A` / 78% | HUD、人物卡、轮盘卡 |
| `WS.Surface.Compact` | `#0C151D` / 68% | 局部信息背衬、底部提示 |
| `WS.Surface.Hover` | `#17222C` / 82% | 悬停、键盘焦点 |
| `WS.Stroke.Hairline` | `#DCE7EE` / 22% | 面板边线、分隔线 |
| `WS.Stroke.Focus` | `#F3F6F8` / 92% | 可交互物 1 px 白描边 |
| `WS.Text.Primary` | `#F3F5F7` | 标题、当前值 |
| `WS.Text.Secondary` | `#B8C2CA` | 标签、摘要 |
| `WS.Text.Muted` | `#77848E` | 禁用、辅助说明 |
| `WS.Accent.Action` | `#F28C28` | 仅 AP、警告、当前交互目标 |
| `WS.Accent.Warning` | `#D9544D` | 危机、关键证据、失败 |
| `WS.Accent.Info` | `#7DB6D6` | 温度、冷色状态信息 |

橙色纪律：`WS.Accent.Action` 不用于普通边框、装饰图标、NPC 姓名或已完成状态。屏幕同一时刻最多保留一个主要橙色焦点。

### 2.2 毛玻璃、圆角与阴影

| Token | 数值 | 用途 |
|---|---:|---|
| `WS.Blur.Compact` | 10 px | HUD 小卡、底部提示 |
| `WS.Blur.Panel` | 16 px | ESC、人物卡、证据板 |
| `WS.Blur.Modal` | 22 px | 对话轮盘、行动确认 |
| `WS.Noise.Opacity` | 3% | 细颗粒，禁止明显噪点 |
| `WS.Radius.Small` | 6 px | 小状态块、按钮 |
| `WS.Radius.Panel` | 12 px | 人物卡、证据卡 |
| `WS.Radius.Modal` | 16 px | ESC 主面板 |
| `WS.Stroke.Panel` | 1 px | 22% 冷白边线 |
| `WS.Stroke.Focus` | 1.25 px | 物体白描边，1080p 基准 |
| `WS.Shadow.Panel` | 0, 8, 28, 42% | 大面板环境分离 |

UE 的 Slate 运行时无法直接做屏幕后处理模糊时，使用带细颗粒的半透明蓝黑九宫格模拟；不得提高不透明度到遮住场景。

### 2.3 字体与字号

字体：`Noto Sans SC`；数字使用等宽数字特性。中文不使用斜体和假粗体。

| Token | 720p | 1080p | 字重 / 用途 |
|---|---:|---:|---|
| `WS.Type.Caption` | 12 | 14 | Regular，键位/辅助 |
| `WS.Type.Body` | 14 | 16 | Regular，正文 |
| `WS.Type.Label` | 15 | 18 | Medium，标签/按钮 |
| `WS.Type.CardTitle` | 17 | 20 | Medium，卡片标题 |
| `WS.Type.Section` | 20 | 24 | Bold，区块标题 |
| `WS.Type.Screen` | 28 | 34 | Bold，屏幕标题 |
| `WS.Type.Cinematic` | 36 | 44 | Bold，开场/危机 |

最小有效字号 12 px（720p）/ 14 px（1080p）。主要文本对背景对比度目标 ≥ 7:1，次要文本 ≥ 4.5:1。

### 2.4 间距与布局

基础间距：4 / 8 / 12 / 16 / 24 / 32 px；面板内边距 16 px（小）或 24 px（大）；卡片间距 10–12 px。安全边距：720p 为 20 px，1080p 为 30 px。

- 左上：局内资源与首要目标，最大屏宽 26%。
- 右侧：玩家/顾衡/叶澄三张人物卡，最大屏宽 22%。
- 底部：控制提示与快捷项，只占内容所需宽度。
- 中央：常态保持空白；只有交互信息、轮盘和模态确认可短时占用。
- 1280×720 时优先缩短文案与隐藏低优先级辅助行，不缩小到最小字号以下。

## 3. 组件规则

### HUD

左上以一张紧凑总览卡显示 8 点 AP、阶段、具象时钟和暴雪抵达时间；下方分离首要目标与现有储备。右侧人物卡均包含肖像、姓名/职务、健康/体温/精力/饥饿/压力等级和信任，不显示规则层不存在的精确血量。底部控制提示在 4 秒无输入后降低到 55% 明度。

### ESC

面板宽度不超过 560 px（1080p）；继续、设置、操作说明、重新开始、返回主菜单可用。存档/读取在未实现前必须显示“当前版本不可用”并禁用，不能伪装可点击。呼出时显示鼠标并切换 `UIOnly`，关闭时恢复 `GameOnly` 与隐藏鼠标。

### 证据板

左侧过滤：全部 / 文件记录 / 物品证据 / 目击信息 / 对话记录。右侧为卡片网格；关键红、重要橙、普通白。底部固定显示 `n / 18`，计数必须来自状态数据。参考图里的日志/任务/人物/地图页不做空壳入口。

### 对话轮盘

轮盘只显示询问、质疑、承诺、安抚、自由输入和取消；命令/交易/隐瞒/威胁不进入 v0.3。当前扇区用细橙弧和轻微亮度变化表示，不整块染橙。右侧 NPC 卡文案来自状态事实。

### 交互高亮与信息卡

焦点物体开启 CustomDepth 白色细描边，禁用整体蓝色 Overlay。信息卡使用墨刷九宫格，顺序为橙色菱形、对象名、AP 成本、`按 F 查看行动`。远距离不出现信息卡；进入可交互距离才显示。

### Toast / 预览 / 拒绝 / 开场 / 结算

全部复用相同表面、描边、字号和橙色纪律。行动预览保留成本、时间、资源、影响、风险、承诺六要素；拒绝卡同时保留原因和可改变条件；结算保留路线、结局、分数、AP 与时间线。

## 4. 图标与位图资产规范

- 源文件：256×256 PNG；图标单色冷白，3 px 视觉线宽，圆角端点，48 px 安全边距。
- 运行时：24 / 32 / 40 px 三档；只允许等比缩放。
- 所有图标使用同一批次提示词与同一笔画体系；不混用 emoji、平台系统图标或临时 Unicode 替代。
- 墨刷底板源文件至少 1024×512，转九宫格时中央 55% 可拉伸、边缘不可拉伸。
- 肖像为 3:4 写实证件式半身近照，冷色柔光、无文字、无品牌、背景简洁；人物卡裁切时保留眼睛与肩线。

统一生成提示词摘要：

> Cold polar-station survival UI; restrained realistic industrial design; crisp monoline white symbols with rounded joins; no text, no logos, no watermark; one coherent batch; strong silhouettes at 24 px; flat removable chroma-key background when alpha is required.

## 6. 验收清单

- 1280×720 与 1920×1080 均无裁切、重叠、超出安全区。
- 常态中央视野无遮挡；面板只包裹内容。
- 呼出 ESC、证据板、轮盘时鼠标显示，关闭后恢复游戏输入。
- 橙色只出现在 AP、警告或当前交互焦点。
- 13 个热点使用白描边且保留本色。
- 图标无 emoji/临时字符；线宽、圆角与留白一致。
- 预览六要素、拒绝原因+改变条件、HUD/结算既有信息均无丢失。
