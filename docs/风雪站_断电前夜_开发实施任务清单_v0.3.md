# 风雪站：断电前夜 — 开发实施任务清单 v0.3

日期：2026-07-22
依据：`docs/风雪站_断电前夜_MVP游戏设计文档_v0.1.docx`、`docs/风雪站_断电前夜_MVP开发实施任务清单_v0.1.docx`、`docs/v0.2真人体验反馈.docx`、`docs/风雪站_断电前夜_开发实施任务清单_v0.2.md`、v0.2 审查报告（含 4 项遗留轻微问题）
版本关系：v0.2 已完成表现层写实化与全中文 UI；v0.3 基于真人体验反馈做体验层打磨与对话系统升级。

## 一、v0.3 范围决策

1. v0.3 = **体验层打磨 + 对话系统升级**。规则依然**零改动**：`Content/Rules`、`Tools/Rules`、`Source/*/State` 保持冻结，冻结哈希继续执行。
2. 全中文 UI 保持；UI 风格升级为反馈指定的"低遮挡黑色毛玻璃 + 墨刷底板"体系。
3. 对话系统升级为"先进入对话、后选方式、半选择半自由输入"，接入 DeepSeek 模型（固定 `deepseek-v4-flash`），但**模型只做意图识别与表达，不改状态、不碰规则**，铁律 §13.1 全部沿用。
4. 反馈参考图（5 张 UI mock）作为**风格依据**；与规则行为集冲突的内容（如轮盘中的命令/交易/隐瞒/威胁）本版不做，记录待规则版本评审。
5. v0.2 审查遗留 4 项轻微问题并入本版（见 V3-19、V3-23、V3-24 及 V3-07 追认）。
6. 所有 AI 生成资产（图标、纹理、肖像）必须登记生成工具、日期与许可，禁止"糊弄替代"。

## 三、执行原则

1. 规则铁律不变：任何 UI/对话/场景调整不得触碰规则层；完成后必须复跑 17 项 Python、6 项 UE 自动化、三路线 AutoRoute，分数与 v0.2 对照不变。
2. **密钥禁令**：LLM API Key 只允许经环境变量或本地不入库配置注入；仓库（含文档、配置、历史）中不得出现明文密钥；每次提交前 `git grep` 扫描。
3. 反馈 mock 图与反馈文字冲突时，**以文字为准**（例：图 2 提示语是"先选方式再选人"，文字要求是"先 F 进入对话再选方式"——按后者执行，图仅作风格参考）。
4. 菜单与界面不得出现"假按钮"：无对应功能的入口必须如实禁用或裁剪。
5. AutoRoute 与自动化测试全程不依赖模型与密钥；模型路径必须可降级、可审计。

## 六、任务详情

### V3-01 密钥注入管线与扫描（M0，G0）
- 目标：LLM 密钥只经环境变量 `WHITEOUT_LLM_API_KEY` 或本地不入库配置文件注入；仓库零密钥。
- 不做：不把密钥写进 DefaultIni、Pak、文档或代码；不破坏现有 `WhiteoutLLMEnabled=false` 降级。
- 执行方式：扩展 `WhiteoutAgentHttp` 的密钥读取顺序（环境变量 → 本地 ini[已 gitignore] → 离线降级）；提供 `LocalConfig/` 模板与填写说明；新增提交前/CI 扫描脚本（grep `sk-` 等模式）。
- 验收：仓库全文与 `git log -p` 扫描无密钥；无密钥环境完整跑通 AutoRoute 三路线。

### V3-02 反馈文档隔离与脱敏（M0，G0）
- 目标：含明文密钥的反馈 docx 永不入库。
- 执行方式：将该文件名/模式加入 `.gitignore`（或移入本地资料目录）；向用户发出密钥轮换建议（清单内不记录密钥本体）；后续如需归档反馈内容，先导出脱敏文本版再入库。
- 验收：`git status` 不含该文件；`.gitignore` 规则生效验证。

### V3-03 模型联调探针（M0，G0）
- 目标：在开发前验证指定模型可用。
- 执行方式：固定模型名 `deepseek-v4-flash`（做成配置项，默认该值）；用注入的密钥发起一次最小 ping 调用，记录时间戳、端点、HTTP 状态与样例响应；若 4xx/模型不存在，**记录证据并回报用户，不静默更换模型**。
- 验收：联调记录入库（脱敏）；结论明确：可用 / 不可用待用户裁决。

### V3-04 UI 风格规范文档（M0，G1）
- 目标：把反馈文字+5 张参考图固化为可执行规范。
- 内容：低遮挡模块化局部背衬（禁大面积整屏底板）；黑/蓝黑毛玻璃（不透明度、背景模糊半径、细颗粒、冷色调）；圆角状态卡/菜单面板；墨刷纹理底板（RDR2 式：中央深、边缘不规则毛刷轮廓、柔和透明渐变）用于准心提示/交互信息/临时通知；文字白/灰白、以字号字重明度分层；**橙色纪律**：仅行动点/警告/当前交互目标；可交互物**细白轮廓描边**，禁整体发光材质；图标线性语言（统一 stroke 宽度、圆角、网格）。
- 验收：`docs/UI_STYLE_v0.3.md` 含完整 token 表（色值/不透明度/字号阶梯/圆角/描边宽）+ 5 张反馈参考图的归档索引。

### V3-05 AI 图标/纹理/肖像资产管线（M0，G1）
- 目标：全套 AI 生成资产，风格统一，禁止糊弄替代。
- 范围：菜单图标 7 项、人物状态图标 5 类、资源图标 6 类、证据类型图标 4 类、重要性标记 3 级、轮盘行为图标（询问/质疑/承诺/安抚/自由输入）、快捷菜单 5 项、键位提示；墨刷底板纹理（九宫格可延展）；顾衡/叶澄写实肖像（对话卡/HUD 用）+ 玩家值班负责人剪影。
- 执行方式：按 V3-04 规范写统一 prompt 模板，单一批次生成；256px PNG 透明底；生成工具/日期/prompt 摘要登记入 `SourceAssets/ASSET_LICENSES.md`；风格抽查。
- 验收：资产清单全覆盖、抽查风格一致、许可登记完整。
