# v0.2 真人盲测准备包

用途：验证新玩家能否在开场 2 分钟内理解目标和行动力，并确认拒绝文案、交互反馈、音频与节奏是否清楚。建议每位参与者单独测试，主持人前两分钟不解释规则。

## 主持人流程

1. 只告诉参与者“双击游戏并开始”，不要说明目标、AP 或操作。
2. 从开场标题出现时计时；2 分钟时暂停观察并提出下列理解题。
3. 允许继续游玩至任一结局。仅当参与者彻底无法继续时才提示，并逐条记录提示内容。
4. 至少观察一次可执行预览、一次拒绝、一次承诺、危机和结算页。

## 两分钟理解检查

请让参与者用自己的话回答，不展示标准答案。

| 问题 | 通过标准 | 结果 / 原话摘要 |
|---|---|---|
| 这一局最重要的三个设备目标是什么？ | 修发电机、校准天线、发求救信号 |  |
| 你有多少行动力？它意味着什么？ | 8 AP；确认行动会消耗，查看界面不消耗 |  |
| 中途可能发生什么危机？ | 备用电池/电压故障，应急负载接管 |  |
| 怎样查看并确认一个行动？ | 看向高亮热点，F 预览，再按 F 确认 |  |
| 怎样退出游戏？ | Esc 菜单退出或 Alt+F4 |  |

判定：前四题至少 3 题无需提示答对，且能独立完成一次“两步确认”，即通过“2 分钟目标理解”。
