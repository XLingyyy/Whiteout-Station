# v0.2 范围基线

状态：已完成并通过 G5 发布门禁（2026-07-21）。

v0.2 是可公开演示的写实风格垂直切片。它保留 v0.1 的全部确定性规则、行动成本、前置条件、状态变化、评分权重、三条成功路线和离线降级能力，只升级玩家可见的场景、人物、界面、反馈、音频与演出。

## 必须完成

- 五区气象站从灰盒升级为可辨识的模块化写实场景，包含暴风雪、状态照明和环境细节。
- 顾衡与叶澄使用可动画的骨骼人物，在固定交互位置提供基础待机、转向和对话动作。
- 所有玩家可见文字为中文；HUD、对话、行动预览、拒绝反馈、证据板和结果页均由 UMG 承载。
- 每个付费行动在提交前显示 AP 成本、条件和可预期影响，并要求确认；失败反馈说明人物原因与可改变条件。
- 开场在两分钟内说明目标、8 AP、危机与交互方式；危机和四类结局具有明确的画面、灯光和音频演出。
- 音频至少覆盖室外风雪、室内风声、电力/机械环境、脚步、UI、危机和结局层。
- 所有外部资产保留来源、许可、校验值和可复现获取/导入脚本。
- 规则冻结校验、17 项 Python 回归、6 项 UE 自动化和三条运行态路线全部通过。
- 形成五区、HUD、证据板、结果页和开场基线截图，并生成 Win64 Shipping 包 `Builds/WhiteoutStation-v0.2-Win64`。

## 明确不改变

- 不修改 v0.1 规则 JSON 与 `Tools/Rules` 实现。
- 不增加战斗、开放世界、随机地图、复杂背包、制造树或多人模式。
- 表现层只读规则快照；查看界面不消耗 AP，也不产生规则事务。
- 生成模型仍只承担受约束的表达，不拥有事实、决策或状态写入权限。
