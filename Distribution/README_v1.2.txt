WHITEOUT STATION: BEFORE THE BLACKOUT - v1.2

Windows 64-bit personal review build.

v1.2 adds grounded free-text dialogue, rule-backed NPC condition reports,
semantic-spine plus optional persona-tail responses, and negotiable condition
cards that can be pinned, accepted, fulfilled, or broken.

Controls
- WASD: move
- Mouse: look
- Space: jump / advance opening
- F: interact / preview / confirm
- Q: switch action option
- E: evidence board
- H: survival handbook
- Esc: back / pause
- Enter: settle phase
- C: load latest compatible autosave
- R: new run

AI integration defaults off. Missing credentials, invalid credentials, network
errors, timeouts, malformed output, and validation failures fall back to the
local deterministic semantic spine. Credentials are process-memory only and
are not included in this package.

The v1.2 project retains the user-edited MVP_StationMap and protected Gu Heng
and Ye Cheng character assets without modification.
