WHITEOUT STATION: BEFORE THE BLACKOUT - v1.1
ONSITE COMPETITION DEMO
风雪站：断电前夜

启动
  Windows\WhiteoutStation.exe

操作
  WASD       移动
  鼠标       观察；点击推进开场；在界面中选择
  F          与人物对话；查看/确认物体行动
  Q          切换行动方案
  E          打开/关闭证据板
  H          打开/关闭生存手册
  Space      逐句推进开场；开场结束后跳跃
  Enter      结束当前阶段
  C          恢复最近自动存档
  R          开始新一轮
  Esc        返回上一层；游戏态打开暂停菜单

v1.1 玩法
  一天分为早晨、下午、傍晚三个阶段，每阶段获得 4 AP，共 12 AP。
  未使用的阶段 AP 会在结算时丢弃。每阶段只能选择一个供暖区，选择
  会影响资源、人物状态、信任、压力、维修条件和后续结局。

  左侧“下一步选择”同时列出当前可行的调查、救治、维修、协商、
  休整与求救方向。它只提供决策信息，不指定单一路线。玩家可以达成
  任务成功、代价失控、生存等待或全面崩溃四类结局。

  室外天线控制终端位于天线基座附近。完成必要维修后，靠近终端，
  按 F 查看校准行动，再按 F 确认；校准成功后可发出求救信号。

语言模型设置
  语言模型默认关闭，完整玩法始终由本地确定性规则完成。暂停菜单的
  设置页可选择 OpenAI、DeepSeek、阿里云百炼、智谱、Kimi、
  SiliconFlow、OpenRouter 或自定义服务，并编辑 BaseURL、API Key
  和模型名。

  API Key 只保存在当前游戏进程内，退出后清除；不会写入 ini、
  存档、日志或分发文件。切换厂商会清除当前会话密钥，需重新输入。
  模型只生成受白名单约束的 NPC 表达；AP、资源、事实、承诺、任务、
  评分和结局均由 C++ 本地规则决定。缺少密钥、断网、超时、非 2xx、
  响应格式错误或校验失败时会立即回退到本地表达。
